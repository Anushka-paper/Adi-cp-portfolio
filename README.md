# CP Portfolio

A competitive programming profile portfolio that auto-syncs stats from Codeforces, LeetCode, and other platforms into one recruiter-friendly page.

See [CP-Portfolio-PRD.md](./CP-Portfolio-PRD.md) for product requirements, [design.md](./design.md) for the visual spec, and [progress-tracker.md](./progress-tracker.md) for build status.

## Getting Started

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
